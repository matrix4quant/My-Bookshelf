# My Bookshelf

一个公开的电子书书架，存放可以合法自由分发的书籍。

## 收录范围

只收录以下两类：

1. **公有领域作品**——著作权保护期已届满，例如先秦诸子、古典名著，以及 Project Gutenberg、维基文库上标注为公有领域的版本。
2. **作者本人作品或已获明确授权的作品**——包括你自己写的书，或持有权利人书面授权、允许公开分发的版本。

**不收录**：仍在版权保护期内的商业出版物，以及从 Z-Library 等渠道获取的电子书。这类文件即使改成私有仓库也不能托管在这里。

## 来源建议

- [Project Gutenberg](https://www.gutenberg.org/) —— 公有领域电子书，epub / txt 格式齐全
- [维基文库](https://zh.wikisource.org/) —— 中文古籍原文，可导出或自行排版成 epub
- [Internet Archive](https://archive.org/) —— 公有领域扫描本
- [Standard Ebooks](https://standardebooks.org/) —— 精排版的公有领域 epub

## 文件格式与目录

- 推荐 `epub`，也可接受 `txt`、`pdf`、`md`
- 文件直接放在仓库根目录，文件名用「书名（版本）.扩展名」
- 每本书请在下方书目表中登记来源与授权依据

直接提交 PR，并在书目表中补上来源链接和授权依据。无法确认版权的书请不要提交。
